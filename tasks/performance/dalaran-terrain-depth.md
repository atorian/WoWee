# Даларан: снимки тайлов и отсечение terrain depth — 2026-10-21

Пункт #2 закоммичен в master: `37360c8` — Reuse renderer frame storage after the last reader releases it.

Пункт #3: вместо копирования глубинной геометрии всех resident terrain chunks в каждый кадр renderer сохраняет неизменяемый снимок каждого тайла. Кадр удерживает ссылки на снимки; загрузка новых чанков инвалидирует только соответствующий тайл. Выгрузка и уплотнение массива живых чанков не меняют уже извлечённые снимки. GPU-ресурсы по-прежнему защищены существующей frame resource lease.

Проходы глубины (солнце, молния, rain shelter, sea bed) сначала проверяют сферу тайла, затем только его прошедшие чанки. Проверка каждого чанка и ортографическое ограничение глубины сохранены; для перспективной проекции это ограничение не применяется. Граница тайла включает сферы всех чанков. Ранее неиспользуемый пересчёт сферы после каждого загружаемого чанка заменён ленивым построением снимка.
