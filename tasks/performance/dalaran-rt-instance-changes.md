# Даларан: инкрементальная RT-синхронизация M2/WMO — 2026-10-21

Средний FPS: **34.12 → 42.46 (+24.5%)**. Это результат нового прогона по сравнению с сохранённым замером после terrain depth optimization; старая версия повторно не запускалась.

В M2 и WMO удалён покадровый полный обход всех экземпляров для синхронизации с RT. Создание, перемещение, изменение hidden/fade, удаление и готовность модели помечают локальные идентификаторы в очереди. Несколько изменений одного экземпляра объединяются, flush читает только его конечное состояние. Удаление убирает RT-привязку до удаления mesh; индексы очереди и состава модели обновляются за O(1) без накопления tombstones при выключенном RT. Состояние перемещается вместе с InstanceSession. Отдельных копий матрицы для сравнения в M2Instance и WMO RT-record больше нет. Ошибка регистрации видна в warning и сама по себе не вызывает попытку каждый кадр.

CPU view-cull M2 теперь использует список кандидатов, уже собранный для GPU-culling. Полный список сохранён, включая экземпляры сверх лимита GPU-буфера; диагностический forceNoCull по-прежнему обходит все экземпляры. Снимки кадров и подтверждаемая очередь RtScene сохранены: пропуск подготовленного кадра не теряет изменения.

Это локальные уведомления о мутациях владельцу сцены, без переделки всей модели мира на event bus. Проход отбора RT-региона при движении камеры, отдельные shadow/animation-проходы и стоимость подготовки видимых draw records остаются следующими кандидатами для оптимизации.

Первый новый replay завершился SIGSEGV без trace. Символизация стека: RangeAllocator::allocate → TerrainRenderer::placeInGeometryPage, одновременно с возвратом диапазонов из deferAfterAllFrameFences. Общая free-list и счётчики не имели синхронизации между producer и render thread. Исправление защищает allocate/free/queries и перемещение allocator mutex-ом; существующий тест дополнен конкурентной проверкой эксклюзивности диапазонов. До исправления тест упал, после проходит. Незавершённый replay исключён из цифр; его лог и crash stack сохранены.

Следующий завершённый прогон run-20261021-215858-374 тоже исключён из сравнения: во время измерения запустился scene_render из параллельного checkout, монитор зарегистрировал 27 пересечений.
